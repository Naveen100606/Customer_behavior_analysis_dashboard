Customer Behavior Data Analysis --- SQL, Python & Power BI

An end-to-end Customer Shopping Behavior Data Analyst Portfolio
Project built to demonstrate practical skills in Python, Pandas,
SQL, PostgreSQL and Power BI.

The project starts with raw customer shopping data, cleans and
transforms it using Python, loads the prepared dataset into PostgreSQL,
answers business questions using SQL, and presents customer and sales
insights through an interactive Power BI dashboard.

Project Overview

The objective of this project is to understand customer purchasing
behavior, spending patterns, product performance, subscriptions,
discounts, shipping preferences, customer loyalty and age-group revenue
contribution.

The dataset contains 37 missing values in the Review Rating column.
These values are handled during the Python data-cleaning stage.

Python / Pandas --- Data Preparation

Python is used for data loading, exploration, cleaning and feature
engineering.

Steps performed

Imported the dataset using Pandas.

Inspected the first few records using head().

Examined dataset structure and data types using info().

Generated summary statistics using describe().

Checked for missing values using isnull().sum().

Imputed missing review ratings using the median review rating of
the corresponding product category.

Standardized column names using snake_case.

Renamed purchase_amount_(usd) to purchase_amount.

Created an age_group feature using age quartiles.

Created purchase_frequency_days by mapping purchase-frequency
categories to approximate day intervals.

Compared discount_applied and promo_code_used.

Removed promo_code_used after confirming both fields contained the
same values.

SQL Analysis --- PostgreSQL

After preparing the data in Python, the cleaned DataFrame is loaded into
a PostgreSQL database.

Database

Database: customer_behavior
Table: customer

SQL is then used to answer business-oriented questions rather than only
performing basic data retrieval.

Business questions answered

What is the total revenue generated by male vs. female
customers?

Which customers used a discount but still spent more than the
average purchase amount?

Which are the top 5 products with the highest average review
rating?

How do average purchase amounts compare between Standard and
Express Shipping?

Do subscribed customers spend more than non-subscribers?

Which 5 products have the highest percentage of purchases with
discounts applied?

How can customers be segmented into New, Returning and Loyal
customers based on previous purchases?

What are the top 3 most purchased products within each category?

Are customers with more than 5 previous purchases more likely to
subscribe?

What is the revenue contribution of each age group?

## How to Run the Project

1. Clone the repository

git clone <your-github-repository-url>
cd <your-project-folder>

2. Open the Jupyter Notebook

Open:

Customer_Shopping_Behavior_Analysis.ipynb

Install the required Python packages if necessary:

pip install pandas sqlalchemy psycopg2-binary

3. Load and clean the data

Run the notebook cells to:

Import the CSV

Explore the dataset

Handle missing values

Rename columns

Create age_group

Create purchase_frequency_days

Remove redundant columns

4. Create the PostgreSQL database

Create a PostgreSQL database named:

customer_behavior

Then use the Python SQLAlchemy connection in the notebook to load the
cleaned DataFrame into:

customer

5. Run SQL analysis

Open:

customer_behavior_sql_queries.sql

Run the queries against the PostgreSQL customer table.

6. Open Power BI

Open:

customer_behavior_dashboard.pbix

Connect Power BI to the PostgreSQL database and use the cleaned customer
table for visualization.
